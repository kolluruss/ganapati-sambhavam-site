# Topic recitation videos

One video per topic, generated from the English markdown source and this
site's synced verse audio, for upload to YouTube. Generated by
`tools/make_topic_video.py` — see that script's docstring for the full
pipeline and format details (Devanagari + IAST captions, 3s image-only
intro, 0.5s gap between verses, H.264/AAC `.mov` editable in QuickTime).

## Layout

```
videos/sarga-<N>/topic-<TT>.mov
```

## Regenerating a video

```bash
python3.9 tools/make_topic_video.py <sarga> <topic>
# e.g.
python3.9 tools/make_topic_video.py 1 1
```

Requires Python 3.8+ (Pillow built with `raqm`, for correct Devanagari
shaping — check with
`python3.9 -c "from PIL import features; print(features.check('raqm'))"`)
and `ffmpeg`/`ffprobe` on `PATH`.

A verse with no synced audio yet in `audio/` is skipped (logged to
stdout), not guessed at or padded with silence — rerun once that verse's
recording is synced to fill it in.
